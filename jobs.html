FEEngineering

POSITION 01

Frontend Developer

พัฒนาเว็บแอปพลิเคชันของ NovaTech ให้รวดเร็ว สวยงาม ใช้งานง่าย และรองรับผู้ใช้ทุกอุปกรณ์ พร้อมนำเครื่องมือ AI Coding มาช่วยเพิ่มประสิทธิภาพตั้งแต่การเขียนโค้ดจนถึงการทดสอบ

สถานที่ทำงานปทุมธานี / Hybrid
รูปแบบงานFull-time
ประสบการณ์0–3 ปี
เงินเดือน40,000–70,000 บาท

01 หน้าที่รับผิดชอบ

  • พัฒนา Client-side Application ด้วย HTML5, CSS3 และ JavaScript ES6+ จากแบบที่ออกแบบใน Figma
  • สร้าง Responsive Layout สำหรับโทรศัพท์ แท็บเล็ต และเดสก์ท็อปตามหลัก Accessibility
  • เชื่อมต่อ REST API และจัดการข้อมูล JSON ร่วมกับทีม Backend
  • ใช้เครื่องมือ AI Coding เช่น GitHub Copilot, Cursor หรือ ChatGPT เพื่อช่วยเขียน Debug และ Refactor โค้ด
  • ปรับปรุง Web Performance, Core Web Vitals และคะแนน Lighthouse ให้ผ่านเป้าหมายของทีม
  • ตรวจสอบและแก้ไขปัญหาการแสดงผลบนเบราว์เซอร์ที่แตกต่างกัน

02 คุณสมบัติผู้สมัคร

  • ปริญญาตรีด้านวิทยาการคอมพิวเตอร์ เทคโนโลยีสารสนเทศ วิศวกรรมคอมพิวเตอร์ หรือสาขาที่เกี่ยวข้อง
  • มีความรู้ HTML5, CSS3 และ JavaScript เป็นอย่างดี พร้อม Portfolio ที่ตรวจสอบได้
  • คุ้นเคยกับ CSS Framework เช่น Tailwind CSS หรือ Bootstrap
  • เข้าใจ Git และการทำงานร่วมกันผ่าน GitHub หรือ GitLab
  • สามารถอ่าน API Documentation และแก้ปัญหาอย่างเป็นระบบ
  • สื่อสารกับ Designer, Backend Developer และ QA ได้ดี

สวัสดิการ

  • สิทธิ์ใช้งานเครื่องมือ AI สำหรับงานพัฒนา
  • ประกันสุขภาพและทันตกรรม
  • งบอบรมและสอบ Certificate
  • กองทุนสำรองเลี้ยงชีพ
  • วันทำงานแบบ Hybrid และเวลาทำงานยืดหยุ่น
พร้อมร่วมสร้างประสบการณ์ดิจิทัลที่ใช้งานได้จริงหรือยังทีมสรรหาจะติดต่อกลับหลังตรวจสอบใบสมัคร

DSData & AI

POSITION 02

Data Scientist

เปลี่ยนข้อมูลของธุรกิจให้เป็นข้อมูลเชิงลึกและแบบจำลอง Machine Learning ที่นำไปใช้งานได้จริง ตั้งแต่การเตรียมข้อมูล การทดลองโมเดล ไปจนถึงการติดตามผลลัพธ์หลังนำระบบขึ้นใช้งาน

สถานที่ทำงานปทุมธานี / Hybrid
รูปแบบงานFull-time
ประสบการณ์1–4 ปี
เงินเดือน45,000–80,000 บาท

01 หน้าที่รับผิดชอบ

  • รวบรวม ทำความสะอาด และตรวจสอบคุณภาพข้อมูลจากหลายแหล่ง
  • วิเคราะห์ข้อมูลเชิงสถิติและสร้าง Dashboard เพื่อสนับสนุนการตัดสินใจ
  • พัฒนา ทดสอบ และเปรียบเทียบโมเดล Machine Learning ให้เหมาะกับโจทย์ธุรกิจ
  • สร้าง Feature Engineering และ Pipeline สำหรับการฝึกและประเมินโมเดล
  • ทำงานร่วมกับ Data Engineer และ Software Developer เพื่อนำโมเดลขึ้นใช้งาน
  • ติดตาม Model Performance, Data Drift และสรุปผลให้ผู้เกี่ยวข้องเข้าใจได้ง่าย

02 คุณสมบัติผู้สมัคร

  • ปริญญาตรีหรือสูงกว่าด้าน Data Science, Computer Science, Statistics, Engineering หรือสาขาที่เกี่ยวข้อง
  • ใช้ Python และ SQL เพื่อวิเคราะห์และจัดการข้อมูลได้คล่อง
  • เข้าใจ Machine Learning, Model Evaluation และหลักสถิติพื้นฐาน
  • มีประสบการณ์ใช้ Pandas, Scikit-learn และเครื่องมือ Data Visualization
  • หากมีความรู้ด้าน Cloud, MLOps หรือ Generative AI จะได้รับการพิจารณาเป็นพิเศษ
  • มีทักษะสื่อสาร สามารถอธิบายผลวิเคราะห์แก่ทีมธุรกิจได้

สวัสดิการ

  • Notebook ประสิทธิภาพสูงและ Cloud Credit
  • ประกันสุขภาพและตรวจสุขภาพประจำปี
  • งบเรียนออนไลน์และสอบ Certificate
  • สิทธิ์เข้าร่วมงานประชุมด้าน Data และ AI
  • วันทำงานแบบ Hybrid และเวลาทำงานยืดหยุ่น
พร้อมเปลี่ยนข้อมูลให้เป็นคำตอบของธุรกิจหรือยังแนบลิงก์ GitHub, Notebook หรือผลงานวิเคราะห์ข้อมูลได้ในใบสมัคร

UXProduct Design

POSITION 03

UX/UI Designer

ออกแบบผลิตภัณฑ์ดิจิทัลตั้งแต่การค้นหาความต้องการของผู้ใช้ วางโครงสร้างประสบการณ์ ไปจนถึงสร้าง Prototype และ Design System ที่ทีมพัฒนานำไปสร้างต่อได้อย่างถูกต้อง

สถานที่ทำงานปทุมธานี / Hybrid
รูปแบบงานFull-time
ประสบการณ์0–3 ปี
เงินเดือน35,000–60,000 บาท

01 หน้าที่รับผิดชอบ

  • วางแผนและดำเนินการ User Research, Interview และ Usability Testing
  • สรุป Pain Point และจัดทำ Persona, User Journey และ User Flow
  • ออกแบบ Wireframe, High-fidelity UI และ Interactive Prototype ด้วย Figma
  • พัฒนาและดูแล Design System ให้สอดคล้องกันในทุกผลิตภัณฑ์
  • ทำงานร่วมกับ Product Manager และ Developer เพื่อตรวจสอบความเป็นไปได้ของงานออกแบบ
  • ตรวจสอบงานที่พัฒนาแล้วและปรับปรุงประสบการณ์จากข้อมูลผู้ใช้งานจริง

02 คุณสมบัติผู้สมัคร

  • ปริญญาตรีด้านการออกแบบ นิเทศศิลป์ เทคโนโลยีสารสนเทศ หรือสาขาที่เกี่ยวข้อง
  • มี Portfolio ที่แสดงกระบวนการคิด ตั้งแต่โจทย์ การวิจัย ไปจนถึงผลงานสุดท้าย
  • ใช้ Figma, Auto Layout, Component และ Prototype ได้อย่างคล่องแคล่ว
  • เข้าใจหลัก Responsive Design, Accessibility และพื้นฐาน Design System
  • เปิดรับ Feedback และสามารถอธิบายเหตุผลของการออกแบบได้ชัดเจน
  • หากเข้าใจพื้นฐาน HTML/CSS หรือเคยออกแบบผลิตภัณฑ์ AI จะได้รับการพิจารณาเป็นพิเศษ

สวัสดิการ

  • Figma Professional และเครื่องมือออกแบบที่จำเป็น
  • ประกันสุขภาพและทันตกรรม
  • งบอบรม UX Research และ Product Design
  • กิจกรรมแลกเปลี่ยนผลงานและ Design Critique
  • วันทำงานแบบ Hybrid และเวลาทำงานยืดหยุ่น
พร้อมออกแบบประสบการณ์ที่ผู้ใช้เข้าใจได้ทันทีหรือยังกรุณาแนบลิงก์ Portfolio หรือ Case Study ในใบสมัคร
